# Google Search Quality Policy

## Purpose

Google Search / AI検索を意識した記事品質の判断基準を、第三者SEO記事ではなくGoogle公式情報へ寄せる。
このResourceは固定SEOテクニック集ではなく、**公開前に最新のGoogle公式方針を再確認するための基準**である。

## Official sources to check

公開前またはGoogle方針に関する主張を行う前に、必要に応じて最新内容を確認する。

- Creating helpful, reliable, people-first content  
  https://developers.google.com/search/docs/fundamentals/creating-helpful-content
- Google Search's guidance on using generative AI content  
  https://developers.google.com/search/docs/fundamentals/using-gen-ai-content
- Google Search Essentials  
  https://developers.google.com/search/docs/essentials
- Spam policies for Google web search  
  https://developers.google.com/search/docs/essentials/spam-policies
- AI features and your website  
  https://developers.google.com/search/docs/appearance/ai-features
- Optimizing for generative AI features on Google Search  
  https://developers.google.com/search/docs/fundamentals/ai-optimization-guide

URLや名称が変更されている場合は、Google Search Central内の現行ページを検索して置き換える。

## Required interpretation rules

- 生成AIの使用そのものを品質低下の根拠にしない。
- AIで大量生成することを目的化せず、独自価値・実体験・一次情報・再現性を中心にする。
- 検索順位、クロール、インデックス、AI Overview / AI Modeでの引用を保証しない。
- Googleが公式に述べていないSEO理論を、Google公式方針として記載しない。
- Google方針の要約と、この記事制作チーム独自の運用ルールを区別する。
- 「検索エンジン向けに文章を作る」より「読者の課題を解決する非コモディティな技術情報」を優先する。

## Content value questions

公開前に最低限以下を確認する。

- この記事は検索結果上位の記事を言い換えただけではないか。
- 実機検証、実測値、失敗、比較、環境固有知見のいずれかがあるか。
- 公式ドキュメントを読むだけでは得られない知見があるか。
- 読者が同条件で追試できるか。
- 読者が記事を読み終えた時、具体的な判断または操作が可能になるか。

## Evidence

Google方針を記事本文で説明する場合もSource Recordを作り、確認日を残す。
Google方針そのものは更新され得るため、Memoryへ固定事実として保存しない。
