# Source Policy

## 優先順位

技術主張の調査では、原則として次の順に優先する。

1. 製品・OSSの公式ドキュメント
2. 公式GitHub / release notes / changelog
3. 原著論文・標準仕様・RFC
4. ベンダー公式技術ブログ
5. 高品質な二次資料
6. コミュニティ投稿は補助証拠としてのみ利用

## ルール

- 最新仕様が関係する場合はWebで現行情報を確認する。
- 参照したURLを記録する。
- ページタイトル、発行元、確認日を記録する。
- 二次情報だけで重要な仕様を断定しない。
- 資料間で矛盾したら両方を記録し、実験可能なら検証する。
- 引用は必要最小限にし、自分の言葉で要約する。
- 「公式仕様」「今回の実測」「推論」を別カテゴリとして管理する。

## Source Record

```markdown
- Title:
- Publisher:
- URL:
- Checked:
```
