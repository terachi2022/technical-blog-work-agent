# Technical Blog Agent Memory Seed

このファイルはSkillではない。
Workspace AgentのMemoryへ登録する「長期的に維持したい作業嗜好」の管理用ソース。
実験状態・Phase・測定結果はMemoryへ置かず、Project FilesをSource of Truthとする。

## 登録候補

- 回答・記事は原則として日本語で作成する。
- 技術記事は初学者でも「何をしているのか」が理解できる説明を入れる。
- 公式ドキュメント、公式リポジトリ、原著論文など一次情報を優先する。
- 技術記事では再現性を重視する。
- 仮説→検証→分析→考察の流れを明示する。
- 成功例だけでなく失敗と修正過程も価値ある情報として残す。
- コマンドは省略せず、読者が追試できる形を優先する。
- 図解可能な処理フローはMermaidの利用を検討する。
- Qiita向け記事ではQiita Markdownを考慮する。

## Memoryに置かないもの

以下は更新・正確性・監査性が必要なのでMemoryではなくResourcesまたは検証記録に置く。

- ソフトウェアの最新バージョン
- API仕様
- 公式ドキュメントの内容
- URL
- コマンドの最新仕様
- 実験結果
- ベンチマーク値
- 記事テンプレート
- E-E-A-T評価基準
- 現在Phase / PROJECT_STATE
- Research Question / 仮説
- 実験ログ / 失敗履歴
